Cohere is an AI platform for building production-grade applications and knowledge systems. Use Cohere's APIs and models to add language understanding, generation, search, retrieval, and agent capabilities to your products.

import cohere

co = cohere.ClientV2(api_key="YOUR_API_KEY")

response = co.chat(
    model="command-a-03-2025",
    messages=[{"role": "user", "content": "What is retrieval-augmented generation?"}]
)

print(response.message.content[0].text)
