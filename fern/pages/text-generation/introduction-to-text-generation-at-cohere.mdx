Cohere's text generation models are accessed through the Chat endpoint. You send a list of messages, and the model returns a generated response. The same endpoint powers single-turn completions, multi-turn conversations, RAG, and tool use.

A basic request looks like this:

```python Python
import cohere

co = cohere.ClientV2()

response = co.chat(
    model="command-a-03-2025",
    messages=[{"role": "user", "content": "Write a title for a blog post about quantum computing."}]
)

print(response.message.content[0].text)
```

The response contains the generated text along with metadata such as token usage and, when applicable, citations or tool calls.
