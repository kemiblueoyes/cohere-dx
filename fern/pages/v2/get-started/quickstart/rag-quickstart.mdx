In this quickstart, you'll make a RAG request using the Chat endpoint and inspect the grounded response and citations it returns.

RAG enables a model to ground its responses on external documents, reducing hallucinations by anchoring the output to a specific source. Cohere's Chat endpoint has built-in support for RAG through the `documents` parameter.

<Steps toc={true}>
### Set up the SDK
Install the Cohere Python SDK.

```bash
pip install -U cohere

```
Import the library and create a client.

```python Python
import cohere

co = cohere.ClientV2("COHERE_API_KEY")  
# Get your free API key at https://dashboard.cohere.com/api-keys
```

### Define documents

Define the documents to pass as context. Each document is a `data` object with any number of fields you choose, such as `title`, `url`, and `text`.

```python Python
documents = [
    {
        "data": {
            "text": "Reimbursing Travel Expenses: Easily manage your travel expenses by submitting them through our finance tool. Approvals are prompt and straightforward."
        }
    },
    {
        "data": {
            "text": "Working from Abroad: Working remotely from another country is possible. Simply coordinate with your manager and ensure your availability during core hours."
        }
    },
    {
        "data": {
            "text": "Health and Wellness Benefits: We care about your well-being and offer gym memberships, on-site yoga classes, and comprehensive health insurance."
        }
    },
]
```
### Generate a response

Call the Chat API by passing the documents in the `documents` parameter. This tells the model to run in RAG-mode and use these documents as the context in its response.

```python Python
# Add the user query
query = "Are there health benefits?"

# Generate the response
response = co.chat(
    model="command-a-plus-05-2026",
    messages=[{"role": "user", "content": query}],
    documents=documents,
)

# Display the response
print(response.message.content[0].text)
```

```mdx wordWrap
Yes, there are health benefits. We offer gym memberships, on-site yoga classes, and comprehensive health insurance.
```

### Inspect citations

The response object contains a `citations` field. Each citation identifies the exact span of text in the model's response that is grounded on a source document.

```python Python
if response.message.citations:
    for citation in response.message.citations:
        print(citation, "\n")
```

```mdx wordWrap
start=14 end=88 text='gym memberships, on-site yoga classes, and comprehensive health insurance.' document_ids=['doc_1'] 
```
In this example, `start` and `end` are the character positions of the cited span within the response text, `text` is the quoted passage from the source document, and `document_ids` identifies which document in your `documents` list the citation maps back to.
