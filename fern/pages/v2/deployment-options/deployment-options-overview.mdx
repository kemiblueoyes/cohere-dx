Cohere models are available through multiple deployment options, so you can choose the setup that best fits your organization's security, compliance, and infrastructure requirements.

## Deployment options
<CardGroup cols={1}>
  <Card title="Cohere Platform">
    The fastest way to get started. Access Cohere models through a fully managed API with no infrastructure setup required. Model Vault is another Cohere-managed option on the Cohere Platform for dedicated, isolated, single-tenant inference with control over model selection, scaling, and performance monitoring.

    [Get started](docs/authentication)

    [Set up Model Vault](/docs/model-vault)
  </Card>
  <Card title="Private deployment">
    Deploy Cohere models securely inside your own controlled environment, either within a private cloud VPC or on-premises. Supports fully network-isolated, air-gapped systems.

    [Set up private deployment (universal)](https://docs.cohere.com/docs/single-container-on-private-clouds)

    [Set up on AWS VPC](https://docs.cohere.com/docs/aws-private-deployment)

    [Read private deployment overview](https://docs.cohere.com/docs/private-deployment-overview)
  </Card>
  <Card title="Amazon Bedrock">
    Access Cohere's Command, Embed, and Rerank models through AWS's fully managed, serverless AI service.

    [Set up Bedrock](https://docs.cohere.com/docs/amazon-bedrock)

    [Read about Bedrock](http://docs.aws.amazon.com/bedrock)

    [View Cohere's models on Amazon Bedrock](https://aws.amazon.com/bedrock/cohere/)
  </Card>
  <Card title="Amazon SageMaker">
    Deploy and customize Cohere models on AWS with full control over infrastructure, instance types, and configuration.

    [Set up SageMaker](https://docs.cohere.com/docs/amazon-sagemaker-setup-guide)

    [Read about SageMaker](https://aws.amazon.com/pm/sagemaker/)

    [View Cohere's models on AWS Marketplace](https://aws.amazon.com/marketplace/seller-profile?id=87af0c85-6cf9-4ed8-bee0-b40ce65167e0)
  </Card>
  <Card title="Microsoft Azure">
    Access Cohere models through Azure AI Foundry on enterprise-grade Microsoft cloud infrastructure.

    [Set up Azure](https://docs.cohere.com/docs/cohere-on-microsoft-azure)

    [View Cohere's models on Azure AI Foundry](https://learn.microsoft.com/en-us/azure/ai-studio/how-to/deploy-models-cohere-command)
  </Card>
  <Card title="OCI">
    Access Cohere's generative and embedding models through Oracle Cloud Infrastructure's fully managed AI service.

    [Set up OCI](https://docs.cohere.com/docs/oracle-cloud-infrastructure-oci)

    [View Cohere's models on OCI](https://docs.oracle.com/en-us/iaas/Content/generative-ai/generate-models.htm)
  </Card>
</CardGroup>
