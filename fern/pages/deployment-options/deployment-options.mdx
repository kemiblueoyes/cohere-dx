## Feature support

The Cohere platform supports the full set of available features. Cloud and private deployment options support subsets of these features. See each platform's documentation for details.

| Method | Cohere Platform | Private Deployment | Azure | Bedrock | Sagemaker | OCI |
| :---- | :---- | :---- | :---- | :---- | :---- | :---- |
| chat\_stream | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| chat | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| generate\_stream (legacy endpoint deprecated in V1 for chat\_stream) | ✅ | ✅ | ✅ | ✅ | ✅ | ⬜️ |
| generate (legacy endpoint deprecated in V1 for chat) | ✅ | ✅ | ✅ | ✅ | ✅ | ⬜️ |
| embed | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| rerank | ✅ | ✅ | ✅ | ✅ | ✅ | ⬜️ |
| classify (deprecated in V1) | ✅ | ✅ | ⬜️ | ⬜️ | ⬜️ | ⬜️ |
| summarize (legacy endpoint deprecated in V1 for chat) | ✅ | ✅ | ⬜️ | ⬜️ | ⬜️ | ⬜️ |
| tokenize | ✅ | ✅ (offline) | ✅ (offline) | ✅ (offline) | ✅ (offline) | ✅ (offline) |
| detokenize | ✅ | ✅ (offline) | ✅ (offline) | ✅ (offline) | ✅ (offline) | ✅ (offline) |
| check\_api\_key (removed in V2) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

**Offline** refers to [tokenization](https://docs.cohere.com/docs/tokens-and-tokenizers#caching-and-optimization) that runs locally without making a network call to Cohere's API. The tokenizer config is downloaded and cached on your local machine, so subsequent tokenization happens without hitting Cohere's servers. In the Cohere Python SDK only, these can be accessed by setting `offline=False`.
