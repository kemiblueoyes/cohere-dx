This reference covers how Cohere calculates usage charges across model types, what `billed_units` means in API responses, and how trial and production API keys are billed. For current per-model prices, see the [Cohere pricing page](https://cohere.com/pricing).

## Pricing units by model type

| Model type | Pricing unit | Billing notes |
| ---------- | ------------ | ------------- |
| Generative (chat models) | Per token | Input tokens and output tokens are priced separately. |
| Rerank | Per search | Each rerank request counts as one search. |
| Embed | Per token | Charges apply to the number of tokens embedded. |

Generative pricing applies to models such as [Command A+](/docs/command-a-plus), [Command A](/docs/command-a), [Command R7B](/docs/command-r7b), [Command R](/docs/command-r), and [Command R+](/docs/command-r-plus).

## Billed tokens vs token counts

API responses include both `tokens` and `billed_units`. The `billed_units` fields are what Cohere uses for billing.

The [Chat API](/reference/chat) returns both values in the response `meta` object:

```json JSON
{
  "billed_units": {
    "input_tokens": 6772,
    "output_tokens": 248
  },
  "tokens": {
    "input_tokens": 7596,
    "output_tokens": 645
  }
}
```

| Field | Description |
| ----- | ----------- |
| `billed_units` | Tokens you are charged for. |
| `tokens` | Total tokens processed, including tokens added by Cohere or generated as special model output. |

`billed_units` and `tokens` can differ when Cohere adds tokens during processing or when a model outputs special tokens you do not control. You are not charged for tokens outside `billed_units`.

The [Rerank](/reference/rerank) and [Embed](/reference/embed) endpoints return their own `billed_units` fields. Rerank reports `search_units` instead of token counts. Embed reports embedded token counts.

## Trial and production API keys

Cohere distinguishes between trial and production API keys for billing.

| Key type | Billing | Usage limits |
| -------- | ------- | ------------ |
| Trial | Free | [Rate-limited](/docs/rate-limits) |
| Production | Paid | Higher limits than trial keys |

Create either key type on the [API keys page](https://dashboard.cohere.com/api-keys). Sign up for a Cohere account on the [registration page](https://dashboard.cohere.com/welcome/register) to get a trial key for evaluation and proofs of concept.
