The Cohere Platform is the managed API for Cohere's models. Call Command, Embed, Rerank, and related models over the API on Cohere's cloud — no infrastructure to manage. Grab an API key and start building in minutes.

Looking for a different product? [Welcome to Cohere](../docs/welcome) compares the Platform, Model Vault, and North.

<Tab title="Python">
```python
import cohere

co = cohere.Client(api_key="COHERE_API_KEY")

response = co.chat(
```

<Tab title="Java">
```java
package chatpost;

import com.cohere.api.Cohere;
import com.cohere.api.requests.ChatRequest;
import com.cohere.api.types.NonStreamedChatResponse;

public class Default {
    public static void main(String[] args) {
        Cohere cohere = Cohere.builder().token("COHERE_API_KEY").clientName("snippet").build();

        NonStreamedChatResponse response = cohere.chat(
                ChatRequest.builder()
                        .model("command-a-plus-05-2026")
                        .message("What is retrieval-augmented generation?")
                        .build());

        System.out.println(response);
    }
}
```
[Cohere SDK for Java on GitHub](https://github.com/cohere-ai/cohere-java)
</Tab>

<Tab title="Go">
```go
package main

import (
	"context"
	"log"

	cohere "github.com/cohere-ai/cohere-go/v2"
	client "github.com/cohere-ai/cohere-go/v2/client"
)

func main() {
	co := client.NewClient(client.WithToken("COHERE_API_KEY"))

	resp, err := co.Chat(
		context.TODO(),
		&cohere.ChatRequest{
			Model:   "command-a-plus-05-2026",
			Message: "What is retrieval-augmented generation?",
		},
	)

	if err != nil {
		log.Fatal(err)
	}

	log.Printf("%+v", resp)
}
```
[Cohere SDK for Go on GitHub](https://github.com/cohere-ai/cohere-go)

## Start building

- **[RAG](../docs/retrieval-augmented-generation-rag)**: Ground model responses in your own data using the Chat endpoint with documents.
- **[Semantic search](../docs/semantic-search-embed)**: Search by meaning, not keywords, using Cohere's Embed models.
- **[Reranking](../docs/rerank)**: Improve retrieval quality by reranking candidate results before generation.
- **[Text generation](../docs/chat-api)**: Generate and refine text using the Chat endpoint and Command models.
- **[Tool use & agents](../docs/tool-use)**: Build agents that call external tools, APIs, and data sources.
- **[Transcription](../docs/transcribe)**: Convert audio to text using Cohere's transcription models.

## Models on the Platform

The Platform gives you API access to Cohere's model families. See the [models overview](../docs/models) for the full list and current versions.

- [Command](../docs/models#command) — text generation for chat, RAG, tool use, and agents
- [Embed](../docs/cohere-embed) — embeddings for semantic search, retrieval, and classification
- [Rerank](../docs/rerank) — relevance ranking for search and retrieval pipelines
- [Transcribe](../docs/transcribe) — speech-to-text across multiple languages
- [Aya](../docs/aya) — open-weight multilingual models for research and underserved languages
