Cohere is an AI platform for building production-grade applications and knowledge systems. Use Cohere's APIs and models to add language understanding, generation, search, retrieval, and agent capabilities to your products.

<Tabs>

<Tab title="Python">
```python
import cohere

co = cohere.ClientV2(api_key="COHERE_API_KEY")

response = co.chat(
    model="command-a-03-2025",
    messages=[
        {
            "role": "user",
            "content": "What is retrieval-augmented generation?",
        }
    ],
)

print(response)
```

<Tab title="Java">
```java
package chatv2post;

import com.cohere.api.Cohere;
import com.cohere.api.resources.v2.requests.V2ChatRequest;
import com.cohere.api.types.*;
import java.util.List;

public class Default {
    public static void main(String[] args) {
        Cohere cohere = Cohere.builder().token("COHERE_API_KEY").clientName("snippet").build();

        ChatResponse response =
                cohere.v2()
                        .chat(
                                V2ChatRequest.builder()
                                    .model("command-a-plus-05-2026")
                                    .messages(
                                        List.of(
                                            ChatMessageV2.user(
                                                UserMessage.builder()
                                                    .content(
                                                        UserMessageContent
                                                                .of("What is retrieval-augmented generation?"))
                                                    .build())))
                                    .build());

        System.out.println(response);
    }
}
```
[Source](https://github.com/cohere-ai/cohere-java)
</Tab>

<Tab title="Go">
```go
package main

import (
	"context"
	"log"

	cohere "github.com/cohere-ai/cohere-go/v2"
	client "github.com/cohere-ai/cohere-go/v2/client"
)

func main() {
	co := client.NewClient(client.WithToken("Your API key"))

	resp, err := co.Chat(
		context.TODO(),
		&cohere.ChatRequest{
			Message: "What is retrieval-augmented generation?",
		},
	)

	if err != nil {
		log.Fatal(err)
	}

	log.Printf("%+v", resp)
}
```
[Source](https://github.com/cohere-ai/cohere-go)

## Start building

- **[RAG](/docs/retrieval-augmented-generation-rag)**: Ground model responses in your own data using the Chat endpoint with documents.
- **[Semantic search](/docs/semantic-search-embed)**: Search by meaning, not keywords, using Cohere's Embed models.
- **[Reranking](/docs/rerank)**: Improve retrieval quality by reranking candidate results before generation.
- **[Text generation](/docs/chat-api)**: Generate and refine text using the Chat endpoint and Command models.
- **[Tool use & agents](/docs/tool-use)**: Build agents that call external tools, APIs, and data sources.
- **[Transcription](/docs/transcribe)**: Convert audio to text using Cohere's transcription models.
