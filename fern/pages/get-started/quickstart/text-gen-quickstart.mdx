In this quickstart, you'll call the Chat endpoint to generate text, maintain a conversation, and stream a response.

Cohere's Command family of models is available through the Chat endpoint. The endpoint powers generative AI applications and provides a conversational interface for building chatbots.

<Steps toc={true}>
### Set up the SDK
Install the Cohere Python SDK.

```bash
pip install -U cohere
```

Import the library and create a client.

```python Python
import cohere

co = cohere.Client("COHERE_API_KEY")
# Get your free API key at https://dashboard.cohere.com/api-keys
```

### Generate text
Call the Chat endpoint by passing the `message` parameter, which contains the user message.

```python Python
response = co.chat(
    model="command-a-plus-05-2026",
    message="I'm joining a new startup called Co1t today. Could you help me write a one-sentence introduction message to my teammates.",
)

print(response.text)
```

```mdx wordWrap
"Excited to be part of the Co1t team, I'm [Your Name], a [Your Role], passionate about [Your Area of Expertise] and looking forward to contributing to the company's success."
```

### Manage conversation state
To maintain the state of a conversation, such as for building chatbots, append a sequence of `user` and `chatbot` messages to the `chat_history` list. You can also include a `preamble` parameter to set the context of the conversation.

```python Python
# The user sends a message
response = co.chat(
    model="command-a-plus-05-2026",
    preamble="You respond in concise sentences.",
    message="Hello",
)

# The model responds
print(response.text)  # Hi, how can I help you today?

# Build the chat history from the first exchange
chat_history = [
    {"role": "user", "message": "Hello"},
    {"role": "chatbot", "message": response.text},
]

# Send a follow-up message
response = co.chat(
    model="command-a-plus-05-2026",
    preamble="You respond in concise sentences.",
    chat_history=chat_history,
    message="I'm joining a new startup called Co1t today. Could you help me write a one-sentence introduction message to my teammates.",
)

print(response.text)
```

```mdx wordWrap
"Excited to join the team at Co1t, looking forward to contributing my skills and collaborating with everyone!"
```

### Stream the response
To stream text generation, call the Chat endpoint using `chat_stream` instead of `chat`. This returns a generator that yields `chunk` objects, which you can access the generated text from.

```python Python
response = co.chat_stream(
    model="command-a-plus-05-2026",
    message="I'm joining a new startup called Co1t today. Could you help me write a one-sentence introduction message to my teammates.",
)

for chunk in response:
    if chunk.event_type == "text-generation":
        print(chunk.text, end="")
```

```mdx wordWrap
"Excited to be part of the Co1t team, I'm [Your Name], a [Your Role/Position], looking forward to contributing my skills and collaborating with this talented group to drive innovation and success."
```
