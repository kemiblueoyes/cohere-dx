The [Cohere Toolkit](https://github.com/cohere-ai/cohere-toolkit) is an open-source, deployable application for building [retrieval augmented generation](/docs/retrieval-augmented-generation-rag) (RAG) products. It bundles pre-built interfaces, a customizable backend API, and retrieval tooling so you can move from prototype to deployment without assembling each layer from scratch.

## When to use the Cohere Toolkit

Use the Cohere Toolkit when you want to:

- Ship a RAG-based product quickly with a working chat UI and backend.
- Test retrieval workflows on custom data sources before investing in a fully custom stack.
- Customize model providers, tools, and data connectors without rebuilding the application shell.
- Deploy locally for development or to cloud environments such as AWS, GCP, or Azure.

If you only need API access to Cohere models, start with the [API reference](/reference/about) or an [SDK](/docs/sdks) instead. Use the Toolkit when you want a deployable application framework, not just model calls.

## How it works

The Toolkit combines three layers:

1. Interfaces for end users, including web applications and a Slack bot.
2. A backend API that handles chat, model routing, and retrieval.
3. Deployment guides for running the stack locally or in production.

You configure which Cohere models to call, which tools and data sources to attach, and which interface to serve. The default setup includes a Next.js web UI with conversation history stored in a local SQL database.

## Key capabilities

### Interfaces

The Toolkit ships with client-side interfaces you can run or replace:

- A default Next.js web UI for chat, with conversation history stored in a SQL database.
- Agentic and basic web application modes.
- A Slack bot implementation.

You can point Docker Compose at a different interface if you want to use your own UI.

### Backend API

The backend in `src/backend` follows a structure similar to the [Chat API](/reference/chat) and adds configurable components:

- Model providers for Cohere Platform, SageMaker, Azure, Bedrock, Hugging Face, and local models.
- Retrieval and tools, including connectors to external data sources.

By default, the Toolkit includes a LangChain retriever for testing RAG on Wikipedia and uploaded documents.

### Customization and extension

Beyond the defaults, you can extend the Toolkit to fit your stack:

- Add [model deployments](https://github.com/cohere-ai/cohere-toolkit/blob/main/docs/command_model_providers.md) for additional providers.
- Register [connectors](https://github.com/cohere-ai/cohere-toolkit/blob/main/docs/how_to_guides.md#how-to-add-a-connector-to-the-toolkit) to external data sources.
- Call the backend [over the API](https://github.com/cohere-ai/cohere-toolkit/blob/main/docs/how_to_guides.md#how-to-call-the-backend-as-an-api) from your own applications.
- Add [custom tools](https://github.com/cohere-ai/cohere-toolkit/blob/main/docs/custom_tool_guides/tool_guide.md), authentication, and theming.

### Deployment options

Run the Toolkit locally with Docker Compose or GitHub Codespaces, or follow the repository's [service deployment guides](https://github.com/cohere-ai/cohere-toolkit/blob/main/docs/service_deployments.md) for AWS, GCP, and Azure.
