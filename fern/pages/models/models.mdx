Cohere offers model families for text generation, embeddings, reranking, multilingual research, agentic coding, and speech transcription. Use this page to see what each family covers, compare live models, and find the right model page or deployment path.

Cohere models are available on the following platforms:

- [Cohere Platform](https://dashboard.cohere.com/playground/chat)
- [Cohere Model Vault](/docs/model-vault)
- [Amazon SageMaker](https://aws.amazon.com/marketplace/seller-profile?id=87af0c85-6cf9-4ed8-bee0-b40ce65167e0)
- [Amazon Bedrock](https://us-west-2.console.aws.amazon.com/bedrock/home?region=us-west-2#/providers?model=cohere.command-r-plus-v1:0)
- [Microsoft Azure AI Foundry](https://ai.azure.com/explore/models/?tid=694fed05-7f6d-4ab2-8c38-9afb438eab6f&selectedCollection=cohere)
- [OCI Generative AI service](https://docs.oracle.com/en-us/iaas/Content/generative-ai/pretrained-models.htm)
- [Hugging Face (as open weights)](https://huggingface.co/CohereLabs)

## Model families

- **[Command](#command):** Text generation for chat, RAG, tool use, agents, translation, reasoning, and vision.
- **[Embed](#embed):** Vector embeddings for semantic search, classification, clustering, and RAG.
- **[Rerank](#rerank):** Relevance reranking for search and retrieval systems.
- **[Aya](#aya):** Multilingual and multimodal models for research and broader language coverage.
- **[North](#north):** Code-focused models for agentic software engineering and terminal-based agents.
- **[Audio](#audio):** Speech-to-text transcription, including an Arabic-optimized variant.

### Embed

Use them through the [Embed](/reference/embed) and [Embed Jobs](/reference/embed-jobs) endpoints. See [supported languages](/docs/supported-languages) for multilingual coverage.

### Rerank

[Rerank models](/docs/rerank) reorder candidate documents by relevance so you can improve existing search systems. Use them through the [Rerank endpoint](/reference/rerank).

<CardGroup cols={2}>
  <Card title="rerank-v4.0-pro" href="/docs/rerank">
    Multilingual reranker for documents and semi-structured data (JSON), optimized for quality and complex use cases.

    - **Context length:** 32k
  </Card>
  <Card title="rerank-v4.0-fast" href="/docs/rerank">
    Lighter multilingual reranker for low-latency, high-throughput workloads.

    - **Context length:** 32k
  </Card>
  <Card title="rerank-v3.5" href="/docs/rerank">
    Reranker for English documents and semi-structured data (JSON).

    - **Context length:** 4k
  </Card>
  <Card title="rerank-english-v3.0" href="/docs/rerank">
    English-language reranker for documents and semi-structured data (JSON).

    - **Context length:** 4k
  </Card>
  <Card title="rerank-multilingual-v3.0" href="/docs/rerank">
    Non-English reranker for documents and semi-structured data; supports the same languages as `embed-multilingual-v3.0`.

    - **Context length:** 4k
  </Card>
</CardGroup>

<Note>
Rerank accepts full strings rather than tokens, so the token limit works differently than generation models. Rerank automatically chunks documents longer than 510 tokens, so there is no explicit maximum document length. See the [reranking best practices](/docs/reranking-best-practices) guide for formatting guidance.
</Note>

### North

North is Cohere's family of code agent models. The first release, [North Mini Code](/docs/north-mini-code-1.0), is a Mixture of Experts model trained for agentic coding. Use it through the [Chat endpoint](/reference/chat).

<CardGroup cols={2}>
  <Card title="north-mini-code-1-0" href="/docs/north-mini-code-1.0">
    30B total / 3B active MoE model for agentic software engineering, terminal-based agents, and local coding workloads.

    - **Context length:** 256k
    - **Max output tokens:** 64k
  </Card>
</CardGroup>

#### North models on different platforms

North Mini Code is available through the Cohere Chat API and as open weights on [Hugging Face](https://huggingface.co/CohereLabs/North-Mini-Code-1.0).

### Next steps

- To pick a text generation model for chat, RAG, or agents, start with [Command A+](/docs/command-a-plus) or [Command A](/docs/command-a).
- To build or improve search and retrieval, read [Embed](/docs/cohere-embed) and [Rerank](/docs/rerank).
- To work across many languages or with open-weight multilingual models, see the [Aya family](/docs/aya).
- To build coding agents, use [North Mini Code](/docs/north-mini-code-1.0).
- To transcribe audio, see [Cohere Transcribe](/docs/transcribe) or [Cohere Transcribe Arabic](/docs/transcribe-arabic).
- To choose where to run models, see [deployment options](/docs/deployment-options-overview).
