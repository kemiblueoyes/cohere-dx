The Cohere API gives you direct access to Cohere's models: Command for text
generation, Embed and Rerank for search and retrieval, and Cohere Transcribe
for speech through a single set of endpoints.

This reference documents Cohere's native API. It is the direct reference for
two deployment options: the Cohere Platform (hosted at `api.cohere.com`) and
private deployment (the same API running on your own infrastructure). 

The same models are also available through Amazon Bedrock, Amazon SageMaker,
Microsoft Azure, and Oracle Cloud Infrastructure (OCI), but those are accessed
through each provider's own API and clients, not the endpoints documented here.
If you deploy through a cloud provider, use this reference to understand model
behavior and parameters, and see [Cohere works everywhere](/docs/cohere-works-everywhere)
for how to call the models on your platform.

## API versions

Cohere's API has two versions, v1 and v2. This reference documents v1. v2 is
the current version and is recommended for new projects. Use the v2 API / v1 API
toggle at the top of any page to switch the documentation and code samples
between versions. In your own code, the SDK client you initialize sets the
version you call, for example, `Client` in Python. To move to v2, see
[Migrating from API v1 to v2](/docs/migrating-v1-to-v2).

## What's in this reference

The API includes endpoints for several purposes:

- The **Chat** endpoint handles text generation, including grounded, cited
  responses for RAG and tool use.
- **Embed**, **Rerank**, and **Embed Jobs** handle search and retrieval. Embed turns text
  into vectors for semantic search, Rerank reorders results by relevance, and
  Embed Jobs handles large-scale embedding.
- The **Transcribe** endpoint converts audio to text.
- **Datasets**, **Tokenize**, and **Models** are utility endpoints that support the
  endpoints above.

Select an endpoint in the sidebar to see its parameters, request and response
schemas, and examples.

## Authentication and base URLs

Every request requires an API key, passed as a Bearer token in the
`Authorization` header:

```bash
Authorization: Bearer COHERE_API_KEY
```

The base URL depends on your deployment. The Cohere Platform uses
`https://api.cohere.com`. Private deployment uses the host where you run the
API. For how to create and manage keys, see [Authentication](/docs/authentication).

## Request format

Requests are sent as HTTP `POST` with a JSON body and return JSON responses.
When a request fails, the API returns a standard HTTP status code and an error
body. See [Errors](/reference/errors) for the full list. For throughput limits,
see [Rate limits](/docs/rate-limits).

## SDKs

The SDK is the recommended way to call the API. The example below makes a basic
v1 `Chat` request in each supported language. For installation, configuration,
and more examples, see [SDKs](/docs/sdks).


<CodeBlocks>
```python Python
import cohere

co = cohere.Client(api_key="COHERE_API_KEY")

response = co.chat(
    model="command-a-plus-05-2026",
    message="Tell me about LLMs",
)

print(response.text)
```

```typescript TypeScript
import { CohereClient } from "cohere-ai";

const cohere = new CohereClient({ token: "COHERE_API_KEY" });

const response = await cohere.chat({
  model: "command-a-plus-05-2026",
  message: "Tell me about LLMs",
});

console.log(response);
```

```java Java
package chatpost;

import com.cohere.api.Cohere;
import com.cohere.api.requests.ChatRequest;
import com.cohere.api.types.NonStreamedChatResponse;

public class Default {
    public static void main(String[] args) {
        Cohere cohere = Cohere.builder().token("COHERE_API_KEY").clientName("snippet").build();

        NonStreamedChatResponse response = cohere.chat(
                ChatRequest.builder()
                        .model("command-a-plus-05-2026")
                        .message("Tell me about LLMs")
                        .build());

        System.out.println(response);
    }
}
```

```go Go
package main

import (
    "context"
    "log"

    cohere "github.com/cohere-ai/cohere-go/v2"
    client "github.com/cohere-ai/cohere-go/v2/client"
)

func main() {
    co := client.NewClient(client.WithToken("COHERE_API_KEY"))

    response, err := co.Chat(
        context.TODO(),
        &cohere.ChatRequest{
            Model:   "command-a-plus-05-2026",
            Message: "Tell me about LLMs",
        },
    )

    if err != nil {
        log.Fatal(err)
    }

	log.Printf("%+v", response)
}

```
